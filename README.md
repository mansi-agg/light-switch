A small browser extension for Chrome and Arc that lets you switch **any website** between light and dark mode, including sites that only offer one, without (hopefully!) distorting photos, videos or charts.


## What it does

- **Three choices for every website:** Off, Dark or Light.
- **Remembers each site.** Set a site once and it stays that way every time you visit.
- **Smart about pages that already match.** If a site already looks the way you asked, nothing is changed.
- **Private.** It does not collect any data. Your choices are stored only in your own browser.

## How to use it

1. Click the **Light Switch** icon (the half-dark, half-light circle) in the browser toolbar.
2. Choose **Off**, **Dark** or **Light** for the website you're on.
3. That's it. The page changes instantly, and your choice is remembered.

## How to install it

Light Switch isn't on the Chrome Web Store yet, so it's installed from its folder:

1. Download this project (green **Code** button → **Download ZIP**) and unzip it. Keep the folder somewhere permanent, such as Documents.
2. Open `chrome://extensions` (Chrome) or `arc://extensions` (Arc).
3. Turn on **Developer mode** (top-right switch).
4. Click **Load unpacked** and choose the unzipped folder (the one that contains `manifest.json`).
5. Click the puzzle-piece icon in the toolbar and **pin** Light Switch.

Websites that were already open need **one refresh** before the extension can work on them.
